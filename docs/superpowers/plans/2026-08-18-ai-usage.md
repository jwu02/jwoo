# AI Usage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an AI Usage page at `/ai-usage` that visualizes records from the MongoDB `ai_usage` collection — summary cards, small-multiple tokens/cost charts, and a per-model breakdown — backed by a new `GET /api/ai-usage` endpoint.

**Architecture:** Follows the existing telemetry pipeline. Pure aggregation functions in `lib/telemetry/aggregation.ts` (tested first), a new API route in `app/api/ai-usage/route.ts`, presentational components under `components/ai-usage/`, and a client page at `app/ai-usage/page.tsx` that polls every 60s with the existing `RangeSelector`.

**Tech Stack:** TypeScript, React 19, Next.js 16, Tailwind CSS 4, shadcn/ui, Recharts, Jest, React Testing Library.

## Global Constraints

- The date field is `recorded_at` (not `createdAt`).
- Cost stays in RMB/¥ — no currency conversion.
- Ranges and bucket intervals are identical to telemetry (24h/7d/1y).
- Never a dual-y-axis chart: tokens and cost are two small-multiple charts sharing an x-axis.
- Cache-Control is `no-store, max-age=0` on the API route.
- All code is written test-first (red → green → refactor).
- Commits end with `Co-Authored-By: Claude <noreply@anthropic.com>`.
