# 3D Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the homepage's card grid with an interactive React Three Fiber + drei 3D scene (MacBook, computer desk, Xiaomi SU7 Ultra) in the existing sidebar frame, where clicking the MacBook navigates to `/activity-telemetry` and the desk/car are hover-only.

**Architecture:** The homepage (`app/page.tsx`, server component) renders a client `HomeScene` that gates on a WebGL availability check: on success it mounts a client-only R3F `<Canvas>` (code-split via `dynamic(..., { ssr: false })` inside the client component, so three/drei never load on the server) with the hero heading overlaid; on failure or a render/model error it falls back to the existing card grid. Models are Draco-compressed and loaded with a locally-bundled decoder (`/draco/`). Click-to-navigate and per-model transforms live in a pure `scene-config.ts` registry.

**Tech Stack:** React Three Fiber 9.7 + drei 10.7 + three 0.185, Next.js 16 App Router, React 19, Tailwind v4, Jest + jsdom.

**Spec:** `docs/superpowers/specs/2026-08-22-3d-homepage-design.md`

## Global Constraints

- **Next.js 16 App Router.** Per `AGENTS.md`, read the relevant guide under `node_modules/next/dist/docs/` before writing framework code (especially `next/dynamic` + client components in this plan).
- **Path alias:** `@/*` → project root (both `tsconfig.json` and `jest.config.js`).
- **Code style:** no semicolons, double quotes, 2-space indent (`.prettierrc`). `npm run lint` (eslint) is the formatting gate.
- **Tests:** Jest + jsdom; `@testing-library/jest-dom` auto-loaded. Tests live under `tests/` mirroring the source tree.
- **Client-only 3D:** three/drei must NEVER render or import during SSR. `ssr: false` dynamic import lives inside the `home-scene.tsx` client component (a Server Component may not use `ssr: false`).
- **Draco decoder served locally** from `/draco/` — no CDN fetch at runtime.
- **Only the MacBook navigates** (to `/activity-telemetry`); desk and car are hover-highlighted but not clickable.
- **`npm run typecheck`, `npm run lint`, and `npm test` must pass** at every commit.

- [ ] **Step 1: Write the compression script**

Create `scripts/compress-glb.mjs`:

```js
// One-time Draco geometry compression for public/*.glb.
// Pristine originals are backed up into public/.glb-originals/ (git-ignored),
// and compression always runs from the backup, so re-running is idempotent.
import { execFileSync } from "node:child_process"
import { copyFileSync, existsSync, mkdirSync, readdirSync } from "node:fs"
import { join } from "node:path"

const root = process.cwd()
const bin = join(root, "node_modules/.bin/gltf-transform")
const inputDir = join(root, "public")
const backupDir = join(root, "public/.glb-originals")

mkdirSync(backupDir, { recursive: true })

for (const file of readdirSync(inputDir)) {
  if (!file.endsWith(".glb")) continue
  const target = join(inputDir, file)
  const backup = join(backupDir, file)
  if (!existsSync(backup)) {
    console.log(`backing up ${file}`)
    copyFileSync(target, backup)
  }
  console.log(`compressing ${file}`)
  execFileSync(bin, ["draco", backup, target], { stdio: "inherit" })
}

console.log("done")
```

```tsx
function LoadingBar() {

  if (!active) return null

      style={{ width: `${progress}%` }}
    />

        camera={{ position: [0, 1.6, 3.4], fov: 45 }}
```

Create `components/home/model-object.tsx`:

```tsx
"use client"

import { Html, useCursor, useGLTF } from "@react-three/drei"
import { useRouter } from "next/navigation"
import { useState } from "react"

import type { HomeSceneModel } from "./scene-config"

export function ModelObject({ model }: { model: HomeSceneModel }) {
  const router = useRouter()
  // Second argument is the local Draco decoder path (drei: UseDraco = boolean | string).
  const { scene } = useGLTF(model.url, "/draco/")
  const [hovered, setHovered] = useState(false)
  useCursor(hovered)

  const highlight = hovered ? 1.03 : 1

  return (
    <group
      position={model.position}
      rotation={model.rotation ?? [0, 0, 0]}
      scale={[
        model.scale[0] * highlight,
        model.scale[1] * highlight,
        model.scale[2] * highlight,
      ]}
      onPointerOver={(event) => {
        event.stopPropagation()
        setHovered(true)
      }}
      onPointerOut={() => setHovered(false)}
      onClick={(event) => {
        event.stopPropagation()
        if (model.target) router.push(model.target)
      }}
    >
      <primitive object={scene} />
      {hovered && model.label ? (
        <Html position={[0, 1.2, 0]} center style={{ pointerEvents: "none" }}>
          <div className="whitespace-nowrap rounded-md border bg-background/90 px-2 py-1 text-xs font-medium text-foreground shadow-sm">
            {model.label}
          </div>
        </Html>
      ) : null}
    </group>
  )
}
```

Create `components/home/home-scene.tsx`:

```tsx
"use client"

import dynamic from "next/dynamic"
import { Component, type ErrorInfo, type ReactNode, useEffect, useState } from "react"

import { HomeFallback } from "./home-fallback"
import { HomeHero } from "./home-hero"

// Client-only: three/drei never loads during SSR (a Server Component cannot use
// ssr:false, so the dynamic import lives in this client component).
const HomeCanvas = dynamic(() => import("./home-canvas"), {
  ssr: false,
  loading: () => null,
})

export function isWebGLAvailable(): boolean {
  if (typeof document === "undefined") return false
  try {
    const canvas = document.createElement("canvas")
    return Boolean(canvas.getContext("webgl2") ?? canvas.getContext("webgl"))
  } catch {
    return false
  }
}

class SceneErrorBoundary extends Component<
  { onError: () => void; children: ReactNode },
  { hasError: boolean }
> {
  state = { hasError: false }

  static getDerivedStateFromError() {
    return { hasError: true }
  }

  componentDidCatch(_error: Error, _info: ErrorInfo) {
    this.props.onError()
  }

  render() {
    return this.state.hasError ? null : this.props.children
  }
}

type SceneMode = "loading" | "scene" | "fallback"

export function HomeScene() {
  const [mode, setMode] = useState<SceneMode>("loading")

  useEffect(() => {
    setMode(isWebGLAvailable() ? "scene" : "fallback")
  }, [])

  if (mode === "scene") {
    return (
      <SceneErrorBoundary onError={() => setMode("fallback")}>
        <div className="relative -mx-4 -mb-4 h-[calc(100vh-3.5rem)] overflow-hidden">
          <div className="absolute inset-0">
            <HomeCanvas />
          </div>
          <div className="pointer-events-none absolute inset-0 z-10 p-6">
            <HomeHero />
          </div>
        </div>
      </SceneErrorBoundary>
    )
  }

  if (mode === "fallback") {
    return <HomeFallback />
  }

  // "loading" — matches SSR output so hydration is consistent; swaps after mount.
  return <div className="-mx-4 -mb-4 h-[calc(100vh-3.5rem)]" />
}
```
